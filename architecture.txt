1. CORE ARCHITECTURE PRINCIPLES
--------------------------------------------------------------------------------

- Fixed Extension ID: Locked permanently via a static RSA public key embedded in

- Modular Deployment: Distinct OAuth credentials for Chrome Service Worker vs. 
  GitHub Pages Web Dashboard.

4. BACKGROUND WORKER AUTHENTICATION (background.js)
--------------------------------------------------------------------------------
Chrome Service Worker acquires tokens silently without popup windows using 
the native identity API.

function getChromeAuthToken(interactive = true) {
  return new Promise((resolve, reject) => {
    chrome.identity.getAuthToken({ interactive }, (token) => {
      if (chrome.runtime.lastError) {
        return reject(new Error(chrome.runtime.lastError.message));
      }
      resolve(token);
    });
  });
}
